# مِحراب الحُفّاظ — المصحف المحمدي الموحد

تطبيق حفظ ومراجعة بالرسم العثماني المغربي (رواية ورش • الوقف الهبطي).

## المصحف المحمدي (صفحات حقيقية)

تمت إضافة عارض **PDF.js** لعرض صفحات المصحف المحمدي كما في النسخة الورقية (الخط المغربي)، وليس نصاً إلكترونياً.

### طريقة الاستخدام

1. افتح التطبيق: https://seddikia1-sketch.github.io/Mihrab/
2. من تبويب المصحف أو مكتبة PDF: **رفع المصحف المحمدي PDF** من هاتفك.
3. بعد الرفع يُحفظ أوفلاين ويُفتح داخل التطبيق مع:
   - تقليب الصفحات
   - تكبير/تصغير
   - الانتقال لصفحة الحزب الحالي
4. يمكنك التبديل إلى «نص إلكتروني (احتياطي)» عند الحاجة.

### الملفات

- `index.html` — الواجهة الرئيسية
- `mushaf-pdf.js` — محرك عرض صفحات المصحف المحمدي
- `manifest.json` / `sw.js` — PWA

### مصدر PDF

المصحف المحمدي الرسمي (مؤسسة محمد السادس لنشر المصحف الشريف) — حوالي 638 صفحة، ورش، خط مغربي.

يمكنك تحميله من مصادر موثوقة تملك الحق في استخدامه، ثم رفعه مرة واحدة داخل التطبيق.
